# 09 · 创新功能与答辩亮点

> 基于 PsyQA 心理港湾已落地版本，可直接写入答辩 PPT / 说明书「创新点」章节。

---

## 凝练版创新亮点（答辩用）

1. **时序化心理研判创新**：从单次问答情绪识别升级为 **EWMA 周期节律分析**，首创学生 **情绪日历 + 周期性心理预警**。
2. **场景化动态 RAG 创新**：基于校园时序节点（考试季/开学季/换季）**自适应调整知识库检索权重**，实现场景化智能应答。
3. **群体 + 个体双维度管控创新**：个体 **高危闭环干预台账** + 院系 **热力群体预警**，兼顾隐私与宏观管理。
4. **轻量化 CBT 落地创新**：将认知行为疗法嵌入即时报告流，**交互式情景练习**同步更新心理画像。
5. **记忆结构化 RAG 创新**：用户记忆 **自动标签 + 锁定加权**，从无序存储到精准个性化检索。

## 一、学生端创新功能

| 功能 | 路径 / API | 创新点 |
|------|-----------|--------|
| 智能情绪节律日历 | `GET /api/questions/emotion-rhythm` · `EmotionRhythmCalendar` | EWMA 时序 + 周期低谷识别（考前/换季/星期规律） |
| CBT 情景疏导小模块 | `GET/POST /api/questions/cbt-*` · `CbtMicroModuleModal` | 焦虑/人际情景选择题，绑定即时报告 |
| 记忆标签智能归档 | `GET/PATCH /api/questions/memory-tag*` | 学业/恋爱/家庭/危机自动标签，锁定条目 RAG 加权 |
| 隐性诉求挖掘 | 内嵌于 `briefReport` · `implicitNeeds` | 从失眠等表面话题挖掘潜在学业压力 |
| 报告智能摘要卡片 | `ReportSummaryCards` | 完整报告生成后 3 条核心结论快览 |

## 四、运维 & 体验

- `/health` 返回 `seasonalRag`（当前季节策略）、`reportQueue`（报告队列）、`dualLlm` 开关状态
- 月度 Excel 台账可嵌入干预记录摘要（与 `intervention_ledgers.json` 联动扩展）

## 五、演示建议（答辩现场）

1. **学生端**：展开趋势区 → 情绪日历（绿黄红）→ 完成一轮咨询 → 打开 CBT 练习 → 查看摘要卡片
2. **学校端**：热力图红色班级 → 干预台账 SLA → 批量授权
3. **技术**：展示 `/health` 中 `seasonalRag.label` 与 `reportQueue.pending`
