# 心理港湾 · 安装与运行

> 系统功能、技术架构与权限说明见 **[系统说明文档.md](./系统说明文档.md)**。

## 环境要求

- Node.js >= 18（建议 20+）
- Ollama（可选，无则使用知识库兜底回复）
- Python 3.8+（可选，仅用于生成 Word 文档或训练脚本）

## 安装与启动

```bash
cd PsyQA
npm run install:all
npm run dev
```

- 前端：http://localhost:3000
- 后端：http://localhost:3001

## 大模型回复（推荐）

默认 **优先智谱 AI**（`ZHIPU_API_KEY` + `PSYQA_LLM_PROVIDER=zhipu`），无需本地 GPU；备选 Ollama `qwen:7b`。

```env
ZHIPU_API_KEY=your_key
ZHIPU_MODEL=glm-4-flash
PSYQA_LLM_PROVIDER=zhipu
```

本地 Ollama（可选）：

```bash
ollama pull qwen:7b
ollama serve
```

若仅需快速演示、不调用大模型，在 `PsyQA/.env` 增加后重启后端：

```env
PSYQA_FAST_ANSWER=1
```

## 生产环境变量（部署）

| 变量 | 说明 |
|------|------|
| `AUTH_SECRET` | **必填**，至少 16 字符的会话签名密钥 |
| `CORS_ORIGIN` | 允许的前端域名，逗号分隔 |
| `PSYQA_SERVE_CLIENT=1` | Docker/单端口部署时由后端托管 `client/build` |
| `PSYQA_ALLOW_GUEST=0` | 生产建议关闭游客 API（`user1` 等） |
| `PSYQA_USE_JSON_STORAGE=1` | 回退为 JSON 文件存储（默认 SQLite） |
| `OLLAMA_EMBED_MODEL` | 嵌入模型，默认 `nomic-embed-text` |

## 常见问题

```powershell
netstat -ano | findstr :3001

```

**无 Ollama 时**：系统仍可通过知识库与规则引擎完成咨询演示，回复可能较短。

## 扩充知识库（爬取/导入）

从 **PsyQA 公开数据集**（CC BY-NC-SA，学术用途）及本地文件合并扩充 `mental_dataset.json` 与向量库：

```bash
pip install requests
python scripts/expand_knowledge_base.py
python scripts/expand_knowledge_base.py --download
python scripts/expand_knowledge_base.py --max-knowledge 800 --max-vector 8000
```

完成后：

```bash
cd PsyQA
npm run tag:knowledge
npm run reload:knowledge
```

自定义问答可放入 `PsyQA/server/data/crawled_import.json`（见 `crawled_import.example.json`）。

> 请仅使用有授权的数据源，勿爬取未授权网站。

## 每月自动更新

每月流水线（计划任务 / 后端调度）**默认包含**：

| 阶段 | 内容 |
|------|------|
| A | 拉取 **PsyQA** + **SoulChat 子集** + **EFAQA**（若已配置 `EFAQA_DL_LICENSE`） |
| B | 归一化语料 → 训练 `psych_model_weights.json` → 合并知识库/向量库 |
| C | `npm run tag:knowledge` 打标签 |

在 `PsyQA/.env` 可配置：

```env
KNOWLEDGE_TRAINING_UPDATE=1
EFAQA_DL_LICENSE=你的证书标识
SOULCHAT_MAX_FILES=2
SOULCHAT_MAX_MB=120
TRAINING_MAX_RECORDS=15000
```

训练依赖：`pip install -r scripts/requirements-training.txt`

### 方式一：Windows 计划任务（推荐，电脑关机也能在开机后补跑）

以**管理员**打开 PowerShell：

```powershell
cd C:\Users\lenovo\Desktop\PsyQA1
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\register_monthly_task.ps1
```

默认 **每月 1 日 03:00** 自动执行：SoulChat 子集 + EFAQA（若有证书）→ 训练权重 → 合并知识库 → 打标签。

手动测试（含 SoulChat/EFAQA 训练阶段）：

```powershell
.\scripts\run_monthly_update.ps1 --force
```

仅更新知识库、跳过训练：

```powershell
.\scripts\run_monthly_update.ps1 --skip-training
```

### 方式二：后端内置调度（服务 7×24 运行）

在 `PsyQA/.env` 增加：

```env
KNOWLEDGE_AUTO_UPDATE=1
KNOWLEDGE_UPDATE_DAY=1
KNOWLEDGE_UPDATE_HOUR=3
KNOWLEDGE_MAX_ITEMS=600
KNOWLEDGE_MAX_VECTOR=6000
KNOWLEDGE_TRAINING_UPDATE=1
EFAQA_DL_LICENSE=你的证书标识
```

重启后端后，每到设定日期的对应小时会自动更新并热加载。

### 方式三：管理员手动触发

登录 `admin` 后调用 API：

- `GET /api/questions/admin/knowledge-status` — 查看上次更新状态
- `POST /api/questions/admin/knowledge-update` — 立即更新（body 可选 `{ "force": true }`）

### 日志与状态

| 文件 | 说明 |
|------|------|
| `logs/knowledge_update/*.log` | 每次更新日志 |
| `PsyQA/server/data/knowledge_scheduler_state.json` | 上次成功月份、条数 |

更多部署说明见 [DEPLOYMENT.md](../DEPLOYMENT.md)。

```bash
pip install -r scripts/requirements-training.txt

```

```bash
npm run fetch:training-data:online
npm run build:training-corpus && npm run train:psych-weights
```
