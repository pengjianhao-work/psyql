# 生产部署指南

## 环境变量

复制 `.env.production.example` 为 `.env`，至少设置：

- `AUTH_SECRET`（≥16 字符）
- `CORS_ORIGIN`（前端访问域名）
- `OLLAMA_API_URL`（若使用大模型）

## Docker Compose（推荐）

```bash
cd PsyQA
docker compose up -d --build
```

- 应用：`http://localhost:3001`
- 健康检查：`GET /health`、`GET /ready`
- Ollama 服务名 `ollama`，容器内地址 `http://ollama:11434`

首次部署后拉取模型：

```bash
docker compose exec ollama ollama pull qwen:7b
```

## 本地构建上线

```bash
npm run install:all
npm run build
NODE_ENV=production npm start
```

生产环境由 Express 托管 `client/build` 静态资源（`PSYQA_SERVE_CLIENT=1`）。

## 性能相关

| 项 | 说明 |
|----|------|
| `compression` | 响应 gzip |
| 仪表盘缓存 | `DASHBOARD_CACHE_TTL_MS`，默认 30s |
| 分类列表缓存 | `CATEGORIES_CACHE_TTL_MS`，默认 5min |
| RAG 检索缓存 | 内存 2min |
| `/api/questions/insights/status` | 轻量轮询，替代全量 progress |
| `/api/v1/*` | 与 `/api/*` 等价，便于网关版本化 |

## 监控

- `GET /health`：运行模式、Ollama 状态
- `GET /api/metrics`：默认生产关闭，设 `PSYQA_ENABLE_METRICS=1` 开启

## 压测模式

仅用于负载测试，勿用于正式环境：

```
PSYQA_LOAD_TEST=1
PSYQA_FAST_ANSWER=1
```
