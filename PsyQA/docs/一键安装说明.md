# 心理港湾 · 一键配置环境安装

> 面向 Windows 用户，**双击 bat 文件**即可完成环境检查、`.env` 配置与依赖安装。

---

## 方式一：双击安装（推荐）

在资源管理器中进入 `PsyQA` 文件夹：

| 文件 | 作用 |
|------|------|
| **`一键安装.bat`** | 检查 Node → 生成 `.env` → `npm install` → 可选拉取 Ollama 模型 |
| **`一键安装-快速模式.bat`** | 同上，并启用 `PSYQA_FAST_ANSWER=1`（**无需 Ollama**） |
| **`一键启动.bat`** | 若未安装则先安装，再 `npm run dev` 启动前后端 |
| **`一键启动-快捷模式.bat`** | 启用 `PSYQA_FAST_ANSWER=1` 后启动（无需 Ollama） |

安装完成后浏览器打开：**http://localhost:3000/login**  
演示账号：`demo` / `demo123`

### 创建桌面快捷方式

双击 **`创建桌面快捷方式.bat`**（或运行 `npm run desktop-shortcuts`），将在桌面生成：

| 快捷方式 | 说明 |
|----------|------|
| 心理港湾 - 启动 | 一键启动前后端 |
| 心理港湾 - 首次安装 | 环境配置 + 依赖安装 |
| 心理港湾 - 快速安装 | 快速模式（无需 Ollama） |
| 心理港湾 - 快捷模式 | 一键启动快捷模式（答辩推荐） |
| 心理港湾 - 打开登录页 | 浏览器打开登录页 |

## 方式二：命令行

```powershell
cd PsyQA
npm run setup          # 标准一键安装
npm run setup:fast     # 快速模式（无大模型）
npm run setup:start    # 安装后直接启动
npm run dev            # 仅启动
```

---

## 脚本会自动完成

1. 检测 **Node.js 18+**（缺失时可尝试 `winget` 安装 LTS）  
2. 从 **`.env.example`** 复制生成 **`.env`**（开发用密钥与 Ollama 地址）  
3. 执行 **`npm run install:all`**（根目录 + client 依赖）  
4. 检测 **Ollama**，询问是否拉取 **`qwen:7b`**（可跳过）  

---

## 前置说明

| 项目 | 是否必须 |
|------|----------|
| Node.js 18+ | **必须** |
| Ollama + qwen:7b | 可选（大模型回复）；快速模式 bat 不需要 |
| Python | 不需要（仅 Word/训练脚本需要） |

## 常见问题

| 问题 | 处理 |
|------|------|
| 提示无法运行脚本 | 已用 `-ExecutionPolicy Bypass`；请直接双击 `.bat` |
| `EADDRINUSE 3001` | 关闭其他 `npm run dev` 窗口或结束 node 进程后重试「一键启动」 |
| 安装很慢 | 首次 `npm install` 正常；可用国内 npm 镜像：`npm config set registry https://registry.npmmirror.com` |
| 不想下 4GB 模型 | 用「**一键安装-快速模式.bat**」 |
