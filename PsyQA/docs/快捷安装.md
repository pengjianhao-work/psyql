# 心理港湾 · 快捷安装（3 步）

> 适用 Windows / macOS / Linux · 约 5～10 分钟（不含下载 Ollama 模型时间）

---

## Windows 一键安装（最省事）

进入 `PsyQA` 文件夹，**双击**：

| 文件 | 说明 |
|------|------|
| **`一键安装.bat`** | 自动配置 `.env` + 安装依赖 + 可选拉取大模型 |
| **`一键安装-快速模式.bat`** | 无需 Ollama，适合答辩现场 |
| **`一键启动.bat`** | 安装并启动，浏览器打开 http://localhost:3000/login |
| **`一键启动-快捷模式.bat`** | 快捷模式启动（规则+知识库，无需 Ollama） |
| **`创建桌面快捷方式.bat`** | 在 Windows 桌面创建 6 个快捷图标 |

详细说明：[一键安装说明.md](./一键安装说明.md)

### 桌面快捷方式（推荐）

双击 **`创建桌面快捷方式.bat`**，桌面将出现：

| 快捷方式 | 用途 |
|----------|------|
| **心理港湾 - 快捷模式** | **答辩演示首选**：规则+知识库，秒开无需 Ollama |
| 心理港湾 | 完整模式：Ollama 大模型 + Chroma 向量检索 |
| 心理港湾 - 打开登录页 | 打开浏览器（未启动时会提示） |
| 心理港湾 - 数据处理 | 知识库 / 向量 / Chroma 一键处理 |
| 心理港湾 - 首次安装 | 第一次配置环境 |
| 心理港湾 - 重建快捷方式 | 重新生成上述图标 |

命令行：`npm run desktop-shortcuts`

## ① 环境（只需 Node.js）

| 项目 | 要求 |
|------|------|
| **Node.js** | ≥ 18（建议 20+） |
| **Ollama** | 可选，推荐（大模型回复） |

检查 Node：

```bash
node -v
npm -v
```

未安装：前往 https://nodejs.org 下载 LTS 版。

---

## ② 安装并启动（复制执行）

```bash
cd PsyQA
npm run install:all
npm run dev
```

| 地址 | 用途 |
|------|------|
| http://localhost:3000/login | **浏览器打开这里** |
| http://localhost:3001 | 后端 API（一般不用直接访问） |

停止服务：终端按 `Ctrl + C`。

## 大模型（推荐，二选一）

**方式 A：完整体验（默认优先大模型）**

```bash
# 另开一个终端
ollama pull qwen:7b
ollama serve
```

未安装 Ollama：https://ollama.com 下载安装后再执行上面命令。

**方式 B：不装 Ollama，快速演示**

在 `PsyQA` 目录新建 `.env` 文件，写入：

```env
PSYQA_FAST_ANSWER=1
```

保存后重新执行 `npm run dev`（规则 + 知识库回复，约 5～15 秒/条）。

## 常见问题

| 现象 | 处理 |
|------|------|
| `EADDRINUSE 3001` | 端口被占用：关掉旧的后端窗口，或任务管理器结束 `node` 后重试 |
| 页面打不开 | 确认 `npm run dev` 无报错，且访问 **3000** 不是 3001 |
| 一直转圈 / 很慢 | 未开 Ollama 时会等超时；设 `PSYQA_FAST_ANSWER=1` 或先 `ollama serve` |
| 登录失败 | 使用上表演示账号；不要用游客 ID 做学校端演示 |
