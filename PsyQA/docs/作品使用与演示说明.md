# 心理港湾 · 作品使用与演示说明

> 完整功能、技术架构与 API 见 **[系统说明文档.md](./系统说明文档.md)**。

## 快速启动

```bash
cd PsyQA
npm run install:all
npm run dev
```

访问 http://localhost:3000/login

| 服务 | 地址 |
|------|------|
| 前端 | http://localhost:3000 |
| 后端 | http://localhost:3001 |

## 演示账号

| 角色 | 用户名 | 密码 | 入口 |
|------|--------|------|------|
| 学生 | demo | demo123 | `/student` |
| 辅导员 | counselor | counselor123 | `/school/dashboard` |
| 管理员 | admin | admin123 | `/school/dashboard` |
| 批量学生 | student01～student20 | Student123456 | 压测/批量演示 |

首次启动会为 `demo` 预置咨询记录与风险告警，便于直接演示学校端。

## 推荐演示流程

### 学生端（约 2 分钟）

1. `demo` 登录 → 伦理与隐私确认
2. 发起咨询（如「最近学习压力很大，睡不着」）
3. 展开 **趋势与报告**：
   - 顶部状态条：咨询次数、情绪、风险（中文标签）
   - **心理咨询报告**：折叠可见情绪/风险/问题摘要；展开查看详细分析
   - 报告底部：**复制摘要**、**分享辅导员**（简短简报，无全文）、**一页纸 PDF**、**导出完整报告**
4. 个人资料：可关闭「允许学校端查看对话原文」

### 风险与学校端（约 2 分钟）

1. 学生端发送含危机关键词内容 → 触发告警
2. `counselor` 登录 → **数据看板** / **风险告警** / **学生列表**（脱敏）
3. 查看学生详情：摘要与指标；原文受学生隐私开关与角色限制

### 管理员（约 1 分钟）

1. `admin` 登录 → 侧栏 **用户管理**（`/school/admin/users`）
2. 看板 **导出全校报表**（CSV / JSON）
3. 说明：需角色 `admin` + 权限 `school:manage`

### 权限校验（可选）

- 学生访问 `/school` → 被重定向
- 辅导员访问 `/school/admin/*` → 403
- 未登录访问咨询接口 → 401

口播脚本见 [03_演示汇报脚本.md](./03_演示汇报脚本.md)。

## 学生报告导出说明

| 操作 | 内容 | 适用 |
|------|------|------|
| 复制摘要 | 摘要 + 完整报告正文 | 自己留存 |
| 分享辅导员 | 情绪/风险/指标简报，**不含**完整报告 | 微信、邮件 |
| 一页纸 PDF | 一页要点 + 报告摘录（打印→另存为 PDF） | 打印、存档 |
| 导出完整报告 | `.txt` 全文 | 离线阅读 |
