# 心理港湾（PsyQA）系统说明文档

> 版本：1.2 · 更新日期：2026-06 · 项目代号 `xinli-gangwan`  
> 适用目录：`PsyQA/`（本仓库主应用）

---

## 1. 项目概述

**心理港湾** 是一套面向高校场景的 **校园心理健康智能咨询与院系管理平台**。系统为学生提供 AI 辅助的心理倾诉与评估，为辅导员提供院系态势看板与风险告警，为管理员提供全校报表导出与用户管理等能力。

设计目标：

- **温暖可用**：对话式咨询、情绪识别、关怀建议与危机提示
- **数据可管**：咨询记录、心理画像、趋势与告警闭环
- **权限分级**：学生 / 辅导员 / 管理员分端访问，对话隐私可配置
- **可离线演示**：无 Ollama 时仍可通过知识库与规则引擎完成基本咨询

## 2. 系统功能

### 2.1 学生端（`/student`）

| 功能模块 | 说明 |
|----------|------|
| 智能咨询 | 多轮对话，智谱/Ollama 大模型 + 混合 RAG（公共库 + 用户私有记忆）+ 规则心理分析 |
| 情绪与风险 | 自动识别情绪类型、问题领域、风险等级（含高危关键词与澄清话术） |
| 心理画像 | 对话结束后异步生成会话画像，前端轮询展示 |
| 个人进度 | 历史摘要、分组历史、自评、趋势与统计报告导出 |
| 个人资料 | 昵称、头像、性别、院系；可设置 **是否允许学校端查看对话原文** |
| 游客模式 | 开发环境支持 `user1`～`user3` 游客 ID（生产应关闭） |
| 危机支持 | 高危场景展示校内/热线支持横幅 |
| 咨询报告 | 可折叠「心理咨询报告」；折叠区展示情绪/风险/问题摘要 |
| 报告获取 | 复制摘要、分享辅导员（简报）、一页纸 PDF、导出完整报告（见下表） |
| 状态条 | `StudentStatusBar` 展示咨询次数、情绪与风险（中文标签） |
| **专属 Agent 档案** | 侧边栏 `AgentProfileCard`：动态 RAG 权重条、基础/干预画像编辑、情绪时序、导出 JSON 配置包（详见 [07_个性化Agent落地方案.md](./07_个性化Agent落地方案.md)） |

**报告导出方式（内容互不重复）**：

| 操作 | 内容 |
|------|------|
| 复制摘要 | 结构化摘要 + **完整报告正文** |
| 分享辅导员 | **简报**（情绪/风险/指标/关注建议/隐私说明），不含全文 |
| 一页纸 PDF | 一页要点 + 核心指标 + 报告摘录（约 380 字），浏览器打印另存 PDF |
| 导出完整报告 | 下载 `.txt` 全文 |

**主要页面/组件**：`StudentApp`、`ReportPanel`、`ChatContainer`、`ConversationPortraitPanel`、`StudentProfileCard`、`AgentProfileCard`、`RagWeightBar`、`ExportMenu` 等。

### 2.2 学校端 · 辅导员（`/school`）

| 功能模块 | 说明 |
|----------|------|
| 数据看板 | 累计咨询、活跃学生、高危人数、待处理告警、问题/情绪 Top3、平均压力等 |
| 风险告警 | 列表筛选、指派、备注、误报标记、状态流转 |
| 学生列表 | 管辖院系内学生档案（姓名、学号、授权状态等） |
| 学生详情 | 咨询摘要、心理指标、咨询画像；**学生已授权**时可查看对话原文 |

辅导员仅可查看其 **管辖院系**（`managedOrgIds`）范围内的数据；未授权或跨院系则仅见摘要与指标。

### 2.3 学校端 · 管理员（`/school`，额外能力）

| 功能模块 | 说明 |
|----------|------|
| 全校报表导出 | 看板页按钮导出 CSV / JSON（`GET /api/school/admin/report`） |
| 用户管理 | 侧栏入口 `/school/admin/users`：新建/编辑用户、角色、院系、重置密码 |
| 知识库维护 | 查看/触发知识库更新（`GET/POST /api/questions/admin/*`） |
| 系统统计 | 全局咨询统计（`GET /api/questions/stats`） |

管理员可查看 **全校** 数据；对话原文默认完整可见（不受学生授权开关限制）。

### 2.4 后台能力（非界面）

- **知识库调度**：支持每月自动更新、Windows 计划任务、管理员 API 触发
- **训练流水线**：公开数据集拉取、语料构建、心理权重训练（Python 脚本，见 `scripts/`）
- **演示数据种子**：启动时注入 demo 学生咨询记录与告警样例

### 2.5 两年长效专属 Agent（增量模块）

面向注册学生的 **24 个月个性化心理陪伴 Agent**，在不重构主架构前提下增量实现：

1. **私有记忆**：每次咨询后 `indexUserDialogMemory()` 写入 Chroma `user_{uid}`
2. **混合 RAG**：`searchBlendedUserMemory()` 按动态权重检索私有 + 公共知识
3. **专属 Prompt**：`buildAgentPromptContext()` 注入画像、近月特征、Agent 人设
4. **动态权重**：时长锚点线性插值（30%→85%）+ 记忆条数加成（详见 [07_个性化Agent落地方案.md](./07_个性化Agent落地方案.md)）
5. **前端**：`AgentProfileCard` + `RagWeightBar` 可视化、编辑与 JSON 导出

大模型默认 **智谱 glm-4-flash**（可配置），月度/年度报告由 LLM 自动生成。

## 3. 角色与权限

### 3.1 角色定义

| 角色 | 标识 | 登录后默认入口 |
|------|------|----------------|
| 学生 | `student` | `/student` |
| 辅导员 | `counselor` | `/school/dashboard` |
| 管理员 | `admin` | `/school/dashboard` |

### 3.2 权限标识（Permission）

| 权限 | 学生 | 辅导员 | 管理员 |
|------|:----:|:------:|:------:|
| `consult:own` | ✓ | | |
| `report:own` | ✓ | | |
| `trend:own` | ✓ | | |
| `school:dashboard` | | ✓ | ✓ |
| `school:alerts:read` | | ✓ | ✓ |
| `school:students:masked` | | ✓ | ✓ |
| `school:transcripts:full` | | 按规则* | ✓ |
| `school:manage` | | | ✓ |

\* 辅导员：学生 `allowSchoolTranscriptView !== false` 且学生属于其管辖院系时，可查看对话原文（后端 `canViewFullTranscripts`）。

路由层通过 `requireAuth`、`requireRole`、`requirePermission` 中间件校验；管理员专属接口挂载在 `/api/school/admin/*`。

### 3.3 隐私策略

- 学生可在资料中关闭 `allowSchoolTranscriptView`，辅导员将无法查看对话原文（仅摘要与指标）；**管理员不受此限制**。
- 列表中的 `maskName` 仅在无显示名时作兜底，管辖范围内展示真实档案信息。
- 管理员报表与用户管理接口需同时具备角色 `admin` 与权限 `school:manage`。

## 4. 技术架构

### 4.1 总体架构

```
┌─────────────────────────────────────────────────────────────┐
│                     浏览器（React SPA）                      │
│  学生端 /student    学校端 /school    登录 /login           │
└───────────────────────────┬─────────────────────────────────┘
                            │ HTTP(S)  REST API
                            │ Cookie: psyqa_session（HttpOnly）
                            │ Header: Authorization: Bearer（兼容）
┌───────────────────────────▼─────────────────────────────────┐
│              Express 后端（Node.js + TypeScript）            │
│  /api/auth   /api/questions   /api/school   /api/school/admin│
└───────┬───────────────┬────────────────┬────────────────────┘
        │               │                │
        ▼               ▼                ▼
   SQLite/JSON     知识库 + 向量库    Ollama（可选）
   账户/对话/告警   mental_dataset    qwen:7b / embed
```

### 4.2 咨询回答流水线（核心）

用户提问经 `answerOrchestrator` 编排，大致顺序为：

1. **规则快筛 + 大模型心理分析并行**：`analyzePsychState` 与 **混合 RAG 检索**（`searchBlendedUserMemory`）并行
2. **专属 Prompt 注入**：`buildAgentPromptContext` 拼装用户画像与动态 RAG 权重说明
3. **推理生成**（默认开启）：按 `PSYQA_AGENT_MODE` 选择 **ReAct**（Thought→Action→Observation）、**Planner-Responder**，或 **ToT 思维树**（展开多分支→评估→选定→生成）；`PSYQA_REACT_ENABLED=0` 或流式失败时回退直连 Prompt
4. **大模型生成回复**：智谱 AI（优先）或 Ollama（`PSYQA_FAST_ANSWER=1` 可关闭）
5. **大模型智能追问**：根据本轮问答生成 2 条「你可能还想了解」
6. **即时返回** + **异步完整报告/画像**
7. **私有记忆入库**：`indexUserDialogMemory` 异步向量化写入 Chroma 用户集合

**性能优化（v1.3）**：
- ReAct **预检索注入**：编排层 RAG 结果传入 Agent，避免重复 Chroma 查询
- **自适应步数**：高危/有预检索时 2–3 步早停
- **Planner-Responder**：`PSYQA_AGENT_MODE=planner` 或 `auto` 下高危/多知识场景 1–2 次 LLM
- **ToT 思维树**：`PSYQA_AGENT_MODE=tot`，多策略分支评估后沿最优路径生成（答辩可展示 expand→evaluate→select→respond）
- **RRF 混合检索**：`mergeRankedReferencesRRF` 融合 TF-IDF 与向量排序
- **嵌入缓存** + **记忆时间衰减**（6/12 月）
- **LLM 熔断** + 指数退避健康检查
- 答案缓存含 `userId` + 风险级别，高危不缓存

相关命令：`npm run chroma:dedupe` · `npm run eval:counsel` · `npm run train:psych-weights:incremental`

### 4.3 数据存储

| 存储 | 默认 | 说明 |
|------|------|------|
| **SQLite** | ✓ | `server/data/psyqa.db`，表：accounts、dialogs、alerts、meta 等 |
| JSON 回退 | 可选 | 设置 `PSYQA_USE_JSON_STORAGE=1` 使用 `accounts.json`、`user_history.json` 等 |

首次启用 SQLite 时，自动从既有 JSON 迁移（`migrateFromJson.ts`）。

### 4.4 认证与会话

- 登录：`POST /api/auth/login`，密码 scrypt 哈希存储
- 会话：签名 Token，生产环境写入 **HttpOnly Cookie** `psyqa_session`
- 登出：`POST /api/auth/logout` 清除 Cookie
- 登录限流：`loginRateLimit` 防暴力尝试
- 生产环境 **必须** 配置 `AUTH_SECRET`（≥16 字符）

| Jest | 服务端单元测试 |

### 5.3 AI 与算法

| 组件 | 说明 |
|------|------|
| **Ollama** | 本地大模型（默认 `qwen:7b`）与嵌入 `nomic-embed-text` |
| **智谱 AI** | 云端 LLM（默认 `glm-4-flash`），`.env` 配置 `ZHIPU_API_KEY` |
| **Chroma** | 向量库：公共知识 + 每用户私有集合（见 doc 05、07） |
| **嵌入模型** | 默认 `nomic-embed-text`，`npm run build:embeddings` 构建向量 |
| **TF-IDF** | 无嵌入时的向量检索兜底 |
| **规则引擎** | 情绪、风险、问题分类与高危词检测 |
| **RAG** | `mental_dataset.json` 知识条目检索 |
| **Python 脚本** | 知识库扩充、训练语料、权重训练（`scripts/`） |

| 变量 | 说明 |
|------|------|

## 10. 安全说明

- 密码使用 **scrypt** 加盐哈希，不明文存储。
- 生产环境强制 `AUTH_SECRET`；Cookie 在生产为 `Secure`。
- 响应头：`X-Content-Type-Options`、`X-Frame-Options`、`Referrer-Policy`。
- 学生咨询接口 `requireStudentAccess`：仅本人或开发游客可访问。
- 学校端接口需登录且角色为辅导员或管理员；管理接口额外校验 `school:manage`。
- 登录接口限流，降低撞库风险。
- _metrics 接口生产默认关闭（`PSYQA_ENABLE_METRICS=1` 可开启）。

## 12. 版本与维护

- **产品名称**：心理港湾  
- **npm 包名**：`xinli-gangwan`  
- **文档版本**：1.1（2026-05）  
- **主要模块**：`server/src/services/question/`（问答编排）、`schoolService` / `schoolAdmin`（学校端）、`client/src/components/ReportPanel.tsx`（学生报告）

**扩展新功能时**：

- 管理端：在 `schoolAdmin` 路由增加接口，`SchoolApp` 侧栏对 `admin` 条件展示入口，`requirePermission('school:manage')` 校验。
- 新权限：在 `accountService` 的 `Permission` 与 `getPermissionsForRole` 中声明。
- 学生报告导出：在 `utils/reportSummary.ts`、`ReportPanel` 底部操作区扩展。
