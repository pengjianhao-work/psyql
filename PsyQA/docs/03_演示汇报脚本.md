# 演示汇报脚本（约 6 分钟）

适用于课堂展示、开题/中期/答辩、项目路演。

---

## 0:00–0:40 开场

> 各位老师好，我们的作品是 **「心理港湾」——面向高校的双端智能心理健康服务平台**。  
> 它解决的核心问题是：学生有倾诉需求但不好意思及时求助，而学校需要 **合规、脱敏** 地掌握风险态势。  
> 我们采用 **学生端 + 学校端** 分离架构，打通「咨询产生数据 → 风险持久化 → 校方查看」完整链路。

## 0:40–2:40 学生端演示（账号 demo / demo123）

1. 登录后进入 **学生端** `/student`，完成 **伦理与隐私声明**
2. 发送示例：「最近学习压力很大，睡不着」
3. 展示 AI 共情回复与参考知识
4. 点击 **展开趋势与报告**：
   - 趋势图、咨询画像（异步生成）
   - **心理咨询报告**：标题栏显示「第 N 次 · 可靠度」；折叠区可见情绪/风险/问题
5. 报告底部演示 **信息获取方式**（四种互不重复）：
   - **复制摘要**：含完整报告
   - **分享辅导员**：简短简报，方便微信/邮件转发
   - **一页纸 PDF**：打印对话框另存为 PDF
6. （可选）个人资料关闭「允许学校端查看对话原文」
7. （可选）危机关键词 → 安全提示与告警写入

## 2:40–4:20 学校端演示

### 辅导员（counselor / counselor123）

1. 登录 → **学校端** `/school`
2. **数据看板**：咨询量、高危人数、待处理告警、问题/情绪 Top3
3. **风险告警**：脱敏学生标识 + 风险摘要
4. **学生列表**：掩码姓名；进入详情查看授权范围内档案

### 管理员（admin / admin123，约 40 秒）

1. 看板 **导出全校报表**（CSV）
2. **用户管理**：新建/编辑账号、重置密码
3. 强调：管理员接口需 `school:manage` 权限校验

## 4:20–5:20 技术亮点

- **双端路由** + 学生 / 辅导员 / 管理员三级权限
- **RAG 知识库** + 情绪 / 风险 / 问题三维分析 + 统计模型融合
- **Ollama 本地可选**，无模型时知识库与规则兜底
- **SQLite 默认存储**，启动可自动从 JSON 迁移；HttpOnly Cookie 会话
- **隐私可控**：学生授权开关 + 辅导员脱敏 + 管理员工单式报表

## 5:20–6:00 收尾

> 本系统为 **大学生作品原型**，提供心理支持参考，不替代专业治疗。  
> 后续可扩展预约咨询、个案工单与校级数据大屏。谢谢各位老师。

## 常见问题预备

| 问题 | 参考回答 |
|------|----------|
| 和 ChatGPT 有何不同？ | 面向校园场景，有心理知识库、风险规则、双端协同、脱敏与告警闭环 |
| 隐私如何保障？ | 学生可关闭对话原文授权；辅导员默认脱敏；会话 HttpOnly Cookie；伦理弹窗 |
| 分享给辅导员会泄露全文吗？ | 不会，「分享辅导员」仅为简报；全文需学生主动「复制摘要」或「导出」 |
| 没有 GPU 能跑吗？ | 可以，无 Ollama 时用知识库兜底，核心流程可演示 |
| 数据是否真实？ | 演示账号含预置样例；正式使用需对接学校统一认证与合规流程 |
