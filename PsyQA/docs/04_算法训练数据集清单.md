# 心理健康算法训练 · 公开数据集清单（v3 · 国内网络适配）

本文档配套三层算法架构（**统计建模 + 机器学习 + 深度学习**），整理完全公开、可落地训练、适配校园心理场景的中文心理健康数据集，覆盖「普通情绪、学业压力、人际困扰、高危心理风险」全场景。

---

> **在线 RAG 向量检索**：默认 TF-IDF + SQLite 嵌入；可选 [Chroma 向量库](./05_Chroma向量库.md)（`PSYQA_CHROMA_ENABLED=1`）。

## 重要前置说明（当前环境适配）

**国内网络现状**：访问 HuggingFace、GitHub 大概率出现超时、解析失败。本项目已实现 **本地优先、在线兜底、镜像回退** 三层策略。

| 场景 | 推荐命令 |
|------|----------|
| **当前环境（默认）** | `npm run pipeline:training:offline` 或 `npm run pipeline:training` |
| **纯离线（断网）** | `npm run fetch:training-data:offline` → `build` → `train` |
| **网络稳定后全量** | `npm run fetch:training-data:online` |

**环境变量**（写入 `PsyQA/.env` 或系统环境）：

```env
TRAINING_LOCAL_FIRST=1          # 本地有缓存则跳过远程（默认开启）
TRAINING_OFFLINE=0              # 设为 1 则完全不发起远程请求
TRAINING_DOMESTIC_ONLY=1        # 仅拉国内源（ModelScope/GitCode/本地 PsyQA）
HF_ENDPOINT=https://hf-mirror.com
TRAINING_CONNECT_TIMEOUT=12
TRAINING_READ_TIMEOUT=90
KNOWLEDGE_MONTHLY_TIER=domestic
```

## 五、网络适配分级策略（落地核心）

### 5.1 在线稳定（外网可用）

```bash
cd PsyQA
npm run fetch:training-data:online
npm run build:training-corpus
npm run train:psych-weights
```

优先拉取 **ModelScope / GitCode**；HuggingFace 走 `hf-mirror.com` 镜像。

### 5.2 网络超时（当前推荐）

1. **本地优先**：已有 `PsyQA/PsyQA_full.json` 或 `training_data/` 缓存时，**零远程请求**直接训练。
2. **外网降级**：用 **EFAQA + SoulChat + R1-10K + TCCI** 替代 HF 超时数据，效果等价。
3. **无感知兼容**：`fetch_training_datasets.py` 自动「本地优先 → 镜像 → 跳过外网」。

```bash
cd PsyQA
npm run pipeline:training          # 国内源 + 本地优先（默认）
npm run pipeline:training:offline  # 纯离线
```

### 5.3 手动离线放置

将数据放入对应目录后执行 `npm run fetch:training-data:offline` 校验：

| 数据集 | 本地路径 |
|--------|----------|
| PsyQA | `PsyQA/PsyQA_full.json` 或 `training_data/psyqa/PsyQA_full.json` |
| EFAQA | `training_data/efaqa/efaqa_corpus.json` |
| SoulChat | `training_data/soulchat/*.json` |
| MentalChat16K 等 HF 源 | `training_data/{id}/samples.jsonl` |
| PsyCrisis | `training_data/psycrisis/PsyCrisis-Bench.xlsx` |
| PsyDial | `training_data/psydial/PsyDial-D3.json` |

## 七点五、LoRA / PEFT 大模型微调（可选后训练）

| 概念 | 说明 |
|------|------|
| **预训练** | Qwen / GLM 等基座在大规模语料上训练（厂商完成） |
| **全量微调 SFT** | 更新全部参数，显存需求高 |
| **PEFT** | HuggingFace 参数高效微调框架（只训少量附加参数） |
| **LoRA** | PEFT 主流方法：在注意力层插入低秩矩阵 \(W + BA\) |
| **QLoRA** | LoRA + 4bit 量化，单卡 8–12GB 可训 1.5B–7B |

**本项目链路**（与在线智谱 API 并行，用于本地 Ollama 部署）：

```bash
cd PsyQA
pip install -r ../scripts/requirements-lora.txt   # GPU + CUDA

npm run pipeline:training                         # 构建 unified_corpus.jsonl
npm run export:lora-dataset                       # → training_data/lora/train.json
npm run train:lora                                # QLoRA 输出 checkpoints + merged

# 或一键
npm run pipeline:lora
```

产出目录：
- `training_data/lora/checkpoints/` — LoRA 适配器（PEFT，体积小）
- `training_data/lora/merged/` — 合并后可导入 Ollama 的全量权重

接入运行时：`.env` 设置 `OLLAMA_MODEL=psyqa-counsel`、`PSYQA_LLM_PROVIDER=ollama`。

**一键导入 Ollama**（Windows）：

```bash
cd PsyQA
npm run pipeline:lora          # 训练 + merge + 生成 Modelfile
npm run import:lora-ollama     # ollama create psyqa-counsel
```

`.env` 启用本地 LoRA 模型：

```env
PSYQA_LLM_PROVIDER=ollama
PSYQA_SKIP_OLLAMA=0
PSYQA_PREFER_LORA=1
PSYQA_LORA_MODEL=psyqa-counsel
OLLAMA_MODEL=psyqa-counsel
```

`/health` 返回 `loraFineTuned: true` 表示后端已自动识别微调模型。
