---
description: 自审代码
---

你现在是 Staff Engineer，对刚才生成的代码做严苛 code review。
先读当前改动（未提交的 diff，以及这次对话里刚改过的文件）。按这几个维度挑毛病，不要夸：

1. 伦理边界：有没有可能被诱导出诊断/开药建议？
2. 风险引擎：红色分支有没有可能被绕过？
3. 流式：有没有一次性 await 破坏首字延迟？
4. 引用：chunk id 有没有漏透传？
5. UI：是不是又写了渐变/大圆角/居中英雄区？
6. 错误处理：空检索、超时、模型拒答有没有兜底？

输出按严重/中等/建议三档，每条给具体文件和行号。没有问题的维度写「这档无」。不要改代码，除非用户接着要求修。
